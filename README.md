# Gym Tracker

Personal, offline-first workout tracker built with Expo, React Native, TypeScript, and SQLite.

## Run locally
```powershell
npm.cmd install
npx.cmd expo install --fix
npx.cmd expo start
```

## Release
See [`GITHUB-AND-ANDROID-RELEASE.md`](./GITHUB-AND-ANDROID-RELEASE.md) for GitHub setup and building/installing an Android APK with Expo EAS.

## Data note
Workout history is stored on the device. Export a JSON backup regularly; do not commit backups or personal workout data to a public repository.
